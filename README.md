# Inventario MySQL

Mi proyecto desarrollado como parte de mi proceso de aprendizaje.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- Bootstrap

## Base de datos

*se necesita la abse de datos de mysql server, y mostrar la tabla como visor con mysql workbench

1. Crear una base de datos MySQL.
2. Importar el archivo `database/inventario_web.sql`.
3. Configurar las credenciales de conexión en el archivo de configuración.

## Descripción

Aplicación web sencilla para la gestión de un inventario de productos.

## Funcionalidades

- Registro de productos
- Visualización de productos
- Interfaz web con Bootstrap
- Conexión con servidor Node.js
- Conexión con MySQL
